# ASDUCK

ASDUCK, mikrofon kullanımını algılayarak seçtiğiniz ses çıkışının seviyesini otomatik olarak düşüren bir Windows uygulamasıdır.

Program özellikle yayın, oyun ve sesli iletişim sırasında arka plandaki müzik veya diğer seslerin konuşma sırasında otomatik olarak kısılmasını sağlar.
